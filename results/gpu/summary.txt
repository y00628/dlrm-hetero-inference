4. Key Takeaways & Architecture Insights
========================================================================================
- PCIe Bottleneck Mitigation:
  CPU-side AVX2 partial pooling reduces 32 cold embedding vectors per bag to a single
  partial sum before transferring over PCIe. This keeps PCIe H2D transfer time tightly
  bounded at 0.34 - 0.51 ms, achieving a 7.5x to 32x reduction in PCIe bus traffic.
- GPU Lookup Linear Scaling:
  GPU embedding lookup latency scales down linearly with the fraction of hot rows on device
  (0.31 ms -> 0.03 ms), confirming effective cache filtering.
- Host Memory Bottleneck:
  As cache ratio drops, latency becomes dominated by CPU DDR4 host gather/pool (1.48 ms -> 6.05 ms),
  reflecting the fundamental ~10x bandwidth gap between host DDR4 DRAM and GPU GDDR6 VRAM.
